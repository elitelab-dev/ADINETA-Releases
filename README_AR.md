# ADINETA Standard v1.0.0

أداة مستقلة لنظام Linux x86_64 لفحص واستطلاع IPv4، مخصصة للأنظمة والشبكات التي يملك المستخدم تصريحًا صريحًا لفحصها.

## التثبيت

```sh
curl -fsSL https://github.com/elitelab-dev/ADINETA-Releases/releases/download/v1.0.0/install.sh | sh
```

يقوم المثبت بتنزيل الحزمة عبر HTTPS، والتحقق من SHA-256، والتثبيت داخل مجلد المستخدم دون صلاحيات root، ثم إتاحة الأمر `adineta` عبر `~/.local/bin`.

## التشغيل

```sh
adineta --help
adineta 127.0.0.1 --ports 1 --transport tcp --report terminal
```

## التوافق

Linux x86_64 على توزيعة تعتمد glibc 2.34 أو أحدث. لا تستهدف هذه الحزمة musl أو معماريات أخرى.

## الاستخدام القانوني والخصوصية

استخدم الأداة فقط على الأنظمة والشبكات المملوكة لك أو المصرح لك بفحصها. قد تحتوي التقارير على عناوين وأرقام منافذ وملاحظات الخدمات والتوقيتات وبيانات الفحص.
